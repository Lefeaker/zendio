# 新手功能体验

首次安装会打开功能体验页。已安装用户从设置页「首次配置」进入同一页面。首页首先呈现保存练习和唯一主要开始按钮；其他课程与进度收在「选择其他练习」中，使用自己的网页也按需展开。下方「设置你的工作流」集中提供默认仓库、真实设置导览和 AI 配置三个入口。旧版五步设置向导已从页面移除，条款与隐私独立折叠，帮助链接与关闭入口保留在页脚。关闭不会把尚未完成的练习计为完成。

## 第一次保存

1. 点击「开始上手练习」，打开扩展内置的两段文章，不需要另找网页。
2. 按浮动提示操作：默认按住 Shift 拖动选中文字，松开鼠标后出现真实剪藏弹窗。提示跟随当前划词设置；关闭划词时需明确点击启用按钮才修改设置。
3. 页面以文章练习区和固定教学栏分工，Shift 等辅助键以键帽显示。弹窗旁每次只显示一个轻提示和弧形箭头：首次保存重点指向「剪藏」，阅读课程重点指向「进入阅读模式」。两个真实按钮始终保留，可先填写批注。
4. 点击「剪藏」保存选段；没有仓库时，旁边会说明保存到浏览器下载文件夹。已有仓库时显示实际选中的目标。
5. 保存完成后，在练习页查看结果与文件位置，可点击「接着体验阅读模式」。

## 阅读编号跳转

阅读练习展开为超过一屏的长文。从剪藏弹窗进入阅读模式后，先跟随箭头收起面板，向下滚动到文章末段，再用相同方式选取文字；它自动成为第二条高亮。随后提示指向面板里的摘抄编号：先点击第一条编号，看页面向上滚回原文，再点击第二条编号，回到末段。引导确认原文确实滚动且对应高亮进入视野，才进入下一步。最后点击「完成并导出」，两处高亮与批注通过原有流程合并保存，可继续进入视频练习。

## 视频时间戳与截图

视频练习提供离线可播的 24 秒短片，画面有大号计时数字和分段颜色，便于观察跳转结果。点击「开始上手练习」打开真实视频面板，按提示在 00:03、00:12 分别添加一条笔记；时刻按钮方便初次定位；窄窗口练习时，播放器和时刻按钮固定在顶部，避免被视频面板遮挡。

提示依次指向两条时间戳的数字。点击数字会通过原视频模式跳到对应时刻并播放，引导确认播放器实际完成跳转后才推进。接着提示指向第一条时间戳旁的圆点：点击空心圆点选择保存该时刻截图，再取消、重新选中，体验保存与不保存的区别。圆点操作不会让可见播放器跳转；后台截取的是该条时间戳对应的画面。完成并导出后，笔记含两个时间戳和实际选中的一张截图。

示例视频为本项目绘制的产品素材，作者源文件为 `tools/generate-practice-video.mjs`。需要修改素材时，通过 `node scripts/run-bounded-command.mjs --profile node-script-standard-v1 -- tools/generate-practice-video.mjs /absolute/path/to/ffmpeg` 重新生成 `public/onboarding/practice.webm`；正常构建直接复制该素材，不依赖 ffmpeg。

划选唤起真实弹窗、进入阅读模式、完成编号或时间戳跳转、尝试截图选择、确认文件保存成功时，会短暂出现一次彩纸礼花。动画不拦截点击，也不计作完成证据；同一阶段重绘、关闭后再开、恢复旧保存结果不会重复播放。系统启用减少动态效果时不播放，退出时清理动画与计时器。

浮动提示不会代替用户点击生产按钮。取消弹窗会返回划选提示，退出可随时回到体验页。选择自己的网页仍保留在折叠入口中。

没有连接 Obsidian 时可以使用 Downloads。下载中的文件、取消的下载、失败的下载不计入完成。文件重名时，显示浏览器最终采用的位置，而不是导出前的预计路径。

保存结果根据实际目的地显示「在下载文件夹中显示」或「在 Obsidian 中打开」，并提供「复制笔记路径」。使用浏览器最终下载路径（含重名调整），或 Vault 名和笔记相对路径。请求显示位置后给出反馈；API 不可用或失败时显示可操作的提示，不静默成功。浏览器接受请求不等于系统窗口一定打开，也不计为用户已读笔记。

## 接着配置自己的工作流

划词练习的按键提示下方给出真实设置路径和直达链接，跳到「捕获行为 → 划词自动触发」的现有控件。用户修改辅助键后，仍打开的练习页通过原配置订阅更新操作提示。

视频保存成功后提供「配置默认仓库」「认识设置页」和「AI 辅助快速配置」入口。默认仓库引导定位存储表格第一行：Chrome、Edge 等支持目录选择的浏览器可选择 Obsidian 仓库根目录并授权读写；Firefox 引导使用 Obsidian Local REST API with MCP，其他浏览器也可选择此方式。说明地址、API Key、Obsidian 保持运行、HTTPS 证书与连接测试，不自动添加仓库、授权或填写配置。

「认识设置页」提供四项基础路线：概览、默认仓库、划词触发、路径模板。下拉菜单按六个设置区分组，另可直接选择 20 个专题：统计、界面语言与外观、隐私、默认仓库、REST 连接、路由、AI 平台链接、视频入口与编辑暂停、附件模板、阅读导出、高亮与 Sidebar Highlights、划词、上下文、快捷键、路径模板、域名映射、YAML、配置迁移、诊断、AI 快速配置。每个专题定位自己的真实控件；空路由表也连同「添加规则」一起高亮。平台列表是网站链接，暂停开关影响编辑批注时的播放。

从默认仓库或其他单专题入口进入，只讲当前任务，结束后可返回对应的片段／阅读／视频练习检查实际保存结果；模板、YAML、AI 等跨内容类型的专题返回练习选择页，避免误用片段练习验证文章设置。也可继续选择另一专题。不会自动推进到多仓库路由，也不把结束讲解记为设置或课程完成。基础路线使用 `guideMode=basics`；专题选择和用户主动切换侧栏时切换为单专题，更新说明、高亮和 URL。刷新保持当前主题与路线，退出移除导览参数。

短窗口将整块导览作为一个可滚动区域，正文不再压缩进小滚动框。可收起为浮动工具条，释放设置区高度，再展开继续；「定位当前设置」用于滚动后回到目标。设置控件获得焦点时也可按 Escape 退出，弹窗自己的 Escape 行为优先。仅在用户编辑时由原 Options 持久化链保存，导览不写配置或学习进度。

阅读步骤说明可选的 Sidebar Highlights；视频附件步骤说明 Custom Attachment Location，提醒附件模板和 Obsidian 插件配置一致，并链接项目说明。视频后的介绍也保留相应设置入口。这些是已有功能的配套说明，不声称自动安装插件或兼容所有第三方插件。

## AI 辅助快速配置

从视频练习结束页、体验页「设置你的工作流」，或设置页「维护与诊断」进入。点击「复制给 AI 的配置说明」，在自己的 AI 对话中粘贴说明并描述需求。说明由当前字段字典生成，包含扩展版本、浏览器、合法值、默认值、模板变量和集合示例；AI 应先询问使用需求，再给出配置。可选择附带当前设置，连接密钥和本机目录授权不在复制范围内。

把 AI 返回的 JSON 或单个 JSON 代码块粘贴到设置页后，页面只解析并在三列表格中显示「修改项／修改前／修改后」，每项占一行，表头仅显示一次；较长值在单元格内换行，窄窗口只让表格区域横向滚动。表格仅显示差异，未改变的项目不显示，也不会保存。点击「应用」才通过原 Options 保存链写入。格式为：

```json
{
  "format": "zendio-ai-config",
  "version": 1,
  "changes": {
    "fragmentClipper.selectionModifierKeys": ["alt"],
    "readingSession.exportMode": "full"
  }
}
```

支持主题、五类笔记路径模板、阅读导出与高亮主题、划词触发与上下文、键盘快捷键、视频提示与编辑时暂停、截图路径和链接模板。域名映射按域名更新；仓库与路由按 ID 更新；YAML 按字段名更新。所有集合都保留未提及的条目，不用省略或空数组删除现有配置。用 `$default` 修改当前默认仓库，不需要猜测 ID。新仓库仍需本机授权或填写连接密钥。

应用前会先处理设置页已有的待保存编辑，再核对预览时的旧值；后台串行写入者也验证同样的条件。同一字段或集合已变化时要求重新检查，不覆盖过时值，其他字段的改动不受影响。当前页面内可「撤销上次应用」，撤销也核对已保存的值；刷新后不保留撤销记录，后续改动不会被强行覆盖。

无效字段、类型、模板变量或目标仓库会阻止应用，并可复制纠错说明给 AI；纠错内容不带输入中的配置值。目录授权、API Key、隐私同意、界面语言与 Obsidian 插件安装需要用户本机操作，应用配置不等于连接测试成功。Firefox 说明使用 REST 方式连接。本功能不接入 AI 服务、不自动发送说明；与原来的完整配置备份导入分别保留。

## 六项基础练习

「功能体验」可以切换练习。切换、打开设置和「稍后体验」不会增加完成数。普通使用中完成对应操作也会更新进度。

| 练习                | 完成依据                                           |
| ------------------- | -------------------------------------------------- |
| 保存一段内容        | 片段真实导出成功                                   |
| 保存整篇网页        | 文章真实导出成功                                   |
| 边读边记            | 导出至少含两处高亮的阅读笔记                       |
| 视频笔记            | 导出含时间戳的笔记及至少一张截图，全部文件保存成功 |
| AI 对话             | 对话真实导出成功                                   |
| 直接保存到 Obsidian | 笔记真实写入 Vault                                 |

只有一个高亮、没有截图的视频笔记仍然正常保存，但不会完成要求更多操作的对应课程。批注是建议操作；基础保存不因批注为空而受阻。

首次剪藏和阅读练习使用内置文章，视频练习使用内置短片；其余练习使用用户自己选择的页面。扩展不依赖在线示例站点，也不会自动登录账号、创建 AI 对话或改变保存模板。Chrome/Chromium 的本地目录与 Firefox 的 REST 连接方式沿用现有设置。Reader、Video 继续使用已有可关闭的首次操作提示。

「设置你的工作流」通过设置导览与 AI 配置覆盖模板、YAML、路由、视频附件、划词触发、草稿恢复、配置迁移和诊断，不重复列出功能说明。它们不计入六项基础练习的自动完成数。

## 数据与实现边界

- 新进度存于本机 `learningProgress.v1`，与统计 consent 无关，不上传笔记正文、路径或来源。
- `src/background/services/learningProgress.ts` 是结果的唯一写入者，串行更新学习状态。用户选择的练习和网页另存 `learningPreference.v1`。
- 既有 `onboardingCompleted` 保留原有引导处理语义；旧 `onboardingCompletedSteps` 不再被用来推断学习完成，也不删除用户的旧值。
- 进度来自 `clipProcessor` 完成的真实写入。Downloads 先保存待确认记录，再由平台下载状态观察及后台重启后的重新检查确认。
- Downloads 必须确认笔记与全部附件都 complete；取消、中断或无法找到下载记录不会被推断为成功。已完成的课程不会被之后的失败清除。
- 进度写入失败不会回滚已经写入的笔记，也不会触发重复导出。重新打开引导可恢复已经持久化的记录；若存储始终不可写，本次记录无法保证恢复。
- 引导页通过 storage 订阅和重新读取更新结果，更新时保留用户尚未提交的 URL 输入。
- 练习页加载与网页相同的 content loader 和剪藏/Reader runtime，视频课通过已有 VideoSession adapter 启动；教学模块只观察真实 UI、滚动和播放器事件。编号访问与圆点练习状态仅保留在当前页面，不增加持久化进度 owner。保存回执新增可选的来源 URL 与课程字段，以含独立 run 参数的 URL 区分不同练习，避免其他标签页的导出误触发本页成功。旧记录兼容且不迁移。
- 视频导出通过已有视频消息链透传可选 `timestampCount`，供真实保存结果识别课程；旧调用方未传该字段时仍兼容。
- 展示值来自最终结果，不能用来源域名、统计上报或页面跳转作为保存成功证明。

## 验证入口

单元回归覆盖进度 owner、下载完成/取消/附件等待/重启、并发导出和引导界面。浏览器回归位于 `tests/visual/learning.onboarding.spec.ts`，通过已安装扩展的真实剪藏浮窗保存文件并读取内容，检查重开引导、跳过和窄屏布局。内置练习回归使用真实 Shift 键和鼠标拖选，覆盖箭头、阅读长文双向编号跳转、实际 Markdown、中文与窄屏。视频回归验证真实播放器双向跳转、圆点开关不触发播放器 seek、实际下载的 Markdown 与 JPEG，检查截图颜色属于所选时间戳而非当前播放时刻。普通网页回归仍使用与右键菜单相同的注入与消息入口，未自动操作浏览器的原生右键菜单。

AI 配置回归位于 `tests/visual/ai.configuration.spec.ts`：从引导进入真实设置页，检查复制说明不含测试密钥、粘贴零写入、应用与撤销、跨页旧预览冲突、集合合并、重载持久化、目录绑定元数据保留及多语言窄屏。还通过应用后的 Alt 划词、包含未摘抄远端段落的全文导出、视频截图的实际下载名及 Markdown 链接确认生产功能采用新设置。目录元数据 fixture 不代表实际完成原生目录授权。

按工程入口使用 bounded profiles 执行测试和构建；生成翻译资源必须通过 catalog generator。

## 升级后的教学入口

从低于 0.3.3 的版本升级到 0.3.3 或更高版本后，在剪藏、阅读或视频面板显示一条非阻塞的功能教学提示。点击入口在新标签页打开已有教学首页，当前选区、批注与会话保持原样；关闭提示或进入教学会共用一份本机确认记录，其他已打开面板同步隐藏，后续打开也不再提示。新安装继续使用首次引导，重复加载同版本及浏览器更新不触发这项提示。

升级事件仅写入独立的可用标记，面板仅写入独立的确认标记，不修改用户设置、教学进度或笔记。提示隐藏时不会抢占焦点；关闭状态写入失败会保留重试入口。旧版调整大小提示在教学提示显示期间暂时让位。

关闭升级提示后，仅当前面板显示一条可点击的说明，告知用户可从 Options 设置页的「首次配置」重新进入教程。该说明不持久化，不会在其他面板或下次打开时重复出现；点击「开始功能教学」则直接进入教学，不显示关闭说明。全新安装通过安装事件自动打开教学首页，浏览器回归检查该入口为自动创建的标签页。
