# 新手功能体验

首次安装会打开「功能体验」。已安装用户可以从设置页原有的引导入口重新进入。

## 第一次保存

1. 点击「开始上手练习」，打开扩展内置的两段文章，不需要另找网页。
2. 按浮动提示操作：默认按住 Shift 拖动选中文字，松开鼠标后出现真实剪藏弹窗。提示跟随当前划词设置；关闭划词时需明确点击启用按钮才修改设置。
3. 页面以文章练习区和固定教学栏分工，Shift 等辅助键以键帽显示。弹窗旁每次只显示一个轻提示和弧形箭头：首次保存重点指向「剪藏」，阅读课程重点指向「进入阅读模式」。两个真实按钮始终保留，可先填写批注。
4. 点击「剪藏」保存选段；没有仓库时，旁边会说明保存到浏览器下载文件夹。已有仓库时显示实际选中的目标。
5. 保存完成后，在练习页查看结果与文件位置，可点击「接着体验阅读模式」。

## 阅读编号跳转

阅读练习展开为超过一屏的长文。从剪藏弹窗进入阅读模式后，先跟随箭头收起面板，向下滚动到文章末段，再用相同方式选取文字；它自动成为第二条高亮。随后提示指向面板里的摘抄编号：先点击第一条编号，看页面向上滚回原文，再点击第二条编号，回到末段。引导确认原文确实滚动且对应高亮进入视野，才进入下一步。最后点击「完成并导出」，两处高亮与批注通过原有流程合并保存，可继续进入视频练习。

## 视频时间戳与截图

视频练习提供离线可播的 24 秒短片，画面有大号计时数字和分段颜色，便于观察跳转结果。点击「开始上手练习」打开真实视频面板，按提示在 00:03、00:12 分别添加一条笔记；时刻按钮方便初次定位；窄窗口练习时，播放器和时刻按钮固定在顶部，避免被视频面板遮挡。

提示依次指向两条时间戳的数字。点击数字会通过原视频模式跳到对应时刻并播放，引导确认播放器实际完成跳转后才推进。接着提示指向第一条时间戳旁的圆点：点击空心圆点选择保存该时刻截图，再取消、重新选中，体验保存与不保存的区别。圆点操作不会让可见播放器跳转；后台截取的是该条时间戳对应的画面。完成并导出后，笔记含两个时间戳和实际选中的一张截图。

示例视频为本项目绘制的产品素材，作者源文件为 `tools/generate-practice-video.mjs`。需要修改素材时，通过 `node scripts/run-bounded-command.mjs --profile node-script-standard-v1 -- tools/generate-practice-video.mjs /absolute/path/to/ffmpeg` 重新生成 `public/onboarding/practice.webm`；正常构建直接复制该素材，不依赖 ffmpeg。

划选唤起真实弹窗、进入阅读模式、完成编号或时间戳跳转、尝试截图选择、确认文件保存成功时，会短暂出现一次彩纸礼花。动画不拦截点击，也不计作完成证据；同一阶段重绘、关闭后再开、恢复旧保存结果不会重复播放。系统启用减少动态效果时不播放，退出时清理动画与计时器。

浮动提示不会代替用户点击生产按钮。取消弹窗会返回划选提示，退出可随时回到体验页。选择自己的网页仍保留在折叠入口中。

没有连接 Obsidian 时可以使用 Downloads。下载中的文件、取消的下载、失败的下载不计入完成。文件重名时，显示浏览器最终采用的位置，而不是导出前的预计路径。

「定位笔记」会调用浏览器显示下载文件，或通过 Obsidian URI 定位 Vault 内的笔记。不能唤起目标应用时，按显示的路径手动查找。系统不把点击定位按钮算作用户已阅读笔记。

## 六项基础练习

「功能体验」可以切换练习。切换、打开设置和「稍后体验」不会增加完成数。普通使用中完成对应操作也会更新进度。

| 练习                | 完成依据                                           |
| ------------------- | -------------------------------------------------- |
| 保存一段内容        | 片段真实导出成功                                   |
| 保存整篇网页        | 文章真实导出成功                                   |
| 边读边记            | 导出至少含两处高亮的阅读笔记                       |
| 视频笔记            | 导出含时间戳的笔记及至少一张截图，全部文件保存成功 |
| AI 对话             | 对话真实导出成功                                   |
| 直接保存到 Obsidian | 笔记真实写入 Vault                                 |

只有一个高亮、没有截图的视频笔记仍然正常保存，但不会完成要求更多操作的对应课程。批注是建议操作；基础保存不因批注为空而受阻。

首次剪藏和阅读练习使用内置文章，视频练习使用内置短片；其余练习使用用户自己选择的页面。扩展不依赖在线示例站点，也不会自动登录账号、创建 AI 对话或改变保存模板。Chrome/Chromium 的本地目录与 Firefox 的 REST 连接方式沿用现有设置。Reader、Video 继续使用已有可关闭的首次操作提示。

进阶区指向已有设置，可继续试用模板、YAML、路由、视频附件、划词触发、草稿恢复、配置迁移和诊断。它们不计入六项基础练习的自动完成数。

## 数据与实现边界

- 新进度存于本机 `learningProgress.v1`，与统计 consent 无关，不上传笔记正文、路径或来源。
- `src/background/services/learningProgress.ts` 是结果的唯一写入者，串行更新学习状态。用户选择的练习和网页另存 `learningPreference.v1`。
- 既有 `onboardingCompleted` 保留原有引导处理语义；旧 `onboardingCompletedSteps` 不再被用来推断学习完成，也不删除用户的旧值。
- 进度来自 `clipProcessor` 完成的真实写入。Downloads 先保存待确认记录，再由平台下载状态观察及后台重启后的重新检查确认。
- Downloads 必须确认笔记与全部附件都 complete；取消、中断或无法找到下载记录不会被推断为成功。已完成的课程不会被之后的失败清除。
- 进度写入失败不会回滚已经写入的笔记，也不会触发重复导出。重新打开引导可恢复已经持久化的记录；若存储始终不可写，本次记录无法保证恢复。
- 引导页通过 storage 订阅和重新读取更新结果，更新时保留用户尚未提交的 URL 输入。
- 练习页加载与网页相同的 content loader 和剪藏/Reader runtime，视频课通过已有 VideoSession adapter 启动；教学模块只观察真实 UI、滚动和播放器事件。编号访问与圆点练习状态仅保留在当前页面，不增加持久化进度 owner。保存回执新增可选的来源 URL 与课程字段，以含独立 run 参数的 URL 区分不同练习，避免其他标签页的导出误触发本页成功。旧记录兼容且不迁移。
- 视频导出通过已有视频消息链透传可选 `timestampCount`，供真实保存结果识别课程；旧调用方未传该字段时仍兼容。
- 展示值来自最终结果，不能用来源域名、统计上报或页面跳转作为保存成功证明。

## 验证入口

单元回归覆盖进度 owner、下载完成/取消/附件等待/重启、并发导出和引导界面。浏览器回归位于 `tests/visual/learning.onboarding.spec.ts`，通过已安装扩展的真实剪藏浮窗保存文件并读取内容，检查重开引导、跳过和窄屏布局。内置练习回归使用真实 Shift 键和鼠标拖选，覆盖箭头、阅读长文双向编号跳转、实际 Markdown、中文与窄屏。视频回归验证真实播放器双向跳转、圆点开关不触发播放器 seek、实际下载的 Markdown 与 JPEG，检查截图颜色属于所选时间戳而非当前播放时刻。普通网页回归仍使用与右键菜单相同的注入与消息入口，未自动操作浏览器的原生右键菜单。

按工程入口使用 bounded profiles 执行测试和构建；生成翻译资源必须通过 catalog generator。
